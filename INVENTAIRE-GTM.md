## 5. Limites et contrôles

- Inventaire statique : il confirme la présence du code, pas le chargement réseau, la configuration des balises dans l’interface Google Tag Manager ni la réception des événements en production.
- Les contenus servis uniquement à distance ne sont pas inclus, à l’exception de leur URL d’iframe lorsqu’elle est visible dans le source.
- Les rapports historiques peuvent être obsolètes : par exemple, certains indiquent « GTM : absent » alors que le HTML actuel contient un chargeur actif. Le code HTML a été retenu pour cet inventaire.
- Contrôle complémentaire : `python -m unittest discover -s tests -p test_restauration_gtm.py -v` — **2 tests réussis**, couvrant 33 pages de référence. L’inventaire récursif ci-dessus couvre les 152 fichiers HTML.
